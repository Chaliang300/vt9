# 系统托盘实时电量环

参考：用户提供的 D:/workbuddyData/2026-10-31-20-57-02/图标清单.html、配套tray SVG及本次粘贴的270°电量环代码。

## 视觉与状态

24×24设计坐标，圆心(12,12)、半径8、描边3.1；从右下角逆时针绘制270°，底部保留缺口。前景弧长严格按0–100%的真实电量计算，0%不画前景，背景环保持可见。

- 高于40%：深色任务栏白色，浅色任务栏#1C2230。
- 20–40%（包含端点）：深色#E8A33D，浅色#C77C1E。
- 低于20%：深色#F2685E，浅色#C0392B。
- 无线：信号弧和点；USB有线：中心实心点。
- 充电：青绿环和闪电，深色#2FA36B、浅色#1E8A57，环长仍按真实电量绘制。
- 未读到电量或断开：空背景环，不展示断开前缓存的前景电量。

用户文字区间写明20–40%为琥珀，而示例脚本用v<40，本次按文字区间包含40%实现。底环透明度按粘贴方案：浅色14%、深色20%。应用程序图标保持原样。

## 实时更新

沿用HID和充电查询的Changed事件，在UI调度线程更新；实际电量每变化1%就重新矢量绘制并替换HICON。缓存键包含电量、无线/有线/充电/离线状态、任务栏深浅色及图标像素尺寸。状态不变不重复分配图标，替换后释放旧HICON及Icon对象。

原有写入成功的400ms靛蓝闪烁移除，改为刷新当前电量环，避免覆盖方案的电量配色。充电不再强制显示至少60%。通知阈值、设备读写协议和系统设置未修改。16/20/24/32像素按设计坐标重新绘制。
