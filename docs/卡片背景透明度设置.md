# 外观设置：卡片与整窗背景透明度

入口：主窗口底部「设置」。

面板按系统风格重做过：18px 半粗标题 + 右上关闭按钮，两组控件各是一张浅底圆角卡片，
底部右对齐「恢复默认 / 完成」两个胶囊按钮，容器是 16 圆角白底 + 11px 投影。
面板内只保留两条透明度滑块，**不再提供颜色选择**：卡片与整窗底色固定为白色 `#FFFFFF`，
可调的只有透明度。

- 滑块范围 0–100%；0% 表示完全不透明，100% 表示完全透明。
- 拖动时实时生效：卡片透明度改的是所有页面的卡片白底画刷，文字、按钮、卡片边框不随之变透明；
  整窗透明度改的是叠在原生 Acrylic 之上的白色蒙层，100% 时完全交给系统材质。
- 默认值：卡片 **45%**、整窗 **80%**（`Preferences` 字段默认值，新装用户即为此值）。
- 「恢复默认」把两条滑块与两个颜色字段一起写回 45% / 80% / `#FFFFFF`。
- 点「完成」、点面板外部、隐藏主窗口或程序退出时保存；下次启动恢复该设置。

配置文件为 `data/settings.json`：

```json
{
  "LowBatteryNotification": false,
  "CardBackgroundTransparency": 45,
  "CardBackgroundColor": "#FFFFFF",
  "WindowBackgroundTransparency": 80,
  "WindowBackgroundColor": "#FFFFFF"
}
```

旧配置缺少字段时使用默认值；显示时将数值限制在 0–100。颜色的 Alpha 按
`round(255 × (100 - 透明度) / 100)` 计算。

实现：

- `src/MainForm.Appearance.cs`：`BuildTransparencyGroup()` 生成单组控件（标题 + 当前值 + 滑块 + 两端刻度），
  `AddAppearanceSettings()` 组装浮层，`ToggleAppearanceSettings()` / `SaveCardAppearance()` 负责开关与保存。
- `src/MainForm.Layout.cs`：`Card()` 使用共享卡片画刷；`BuildSurface()` 用整窗蒙层画刷；
  `buttonStyle` 模板的 `ContentPresenter` 绑定 `Padding`，浮层里的两个按钮因此有内边距。
- `src/Program.cs`：`Preferences` 的四个字段与上面的默认值。

验证：`--ui-preview-bg --page=settings` 会渲染主窗口并展开该浮层，截图落在
`artifacts/1.14-fonts/data/ui-preview-bg-settings.png`（2026-11-01 实机截图，滑块显示 45% / 80%，
两个按钮为正常胶囊宽度）。
