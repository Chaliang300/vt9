# 提示词 v2：左侧栏拖动跟手切换 + 点击切换（按四条动效原则）

v2 相对 v1 的改动：把"动画参数"改成"原则优先"，并按原则重写了过渡方式 ——
退场不再飞出屏幕（改成移 48px + 淡出 + 模糊）、入场改成起步快收尾轻（取消慢起）、
状态切换一律交叉淡化、并且明确要求所有动画可随时打断。
`src/SlideEase.cs` 也已按第 4 条改成 `1−(1−t)³` + 末段 2% 回弹。

下面代码块里的内容可以直接整段投给编码 agent。

```text
任务：给 VT9Status（C# WPF + WinForms 托盘）的左侧导航栏加「拖动跟手切换 + 点击切换」，
动效按下面四条原则做，不要为了"好看"牺牲跟手与可打断。

工作目录：C:\Users\26451\Desktop\ces

【四条原则（优先级高于任何具体参数）】
1. 只用可随时打断的过渡动画。一律用 from→to 的 DoubleAnimation（属性动画）；
   禁止 DoubleAnimationUsingKeyFrames / Storyboard 关键帧 —— 它们被打断就得从头重放。
   任何新输入（新的拖拽、新的点击）到来时：先读该属性当前值（读属性会拿到动画中的实时值），
   从当前值续接到新目标，并把时长按剩余距离缩放，绝不重置回起点。
2. 退场不要飞出屏幕。元素只移一小段（≤48px），主要靠淡出 + 高斯模糊收尾；
   飞出去会显得"被打发走"，糊掉才是柔和退场。
3. 状态/图标切换用交叉淡化 + 轻微缩放 + 模糊，不要硬切（不要一帧直接换值）。
4. 入场起步快、收尾轻（ease-out），不要匀速、更不要慢起。
   慢起会让界面显得不跟手 —— "先拉长"的那段由手指拖拽本身承担（拖动期 1:1 跟手、不加缓动）。

【项目事实（动手前必看）】
1. 没有 NuGet / .sln / .csproj：build.ps1 用系统 .NET Framework 的 csc 全量编译 src\*.cs。
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputDirectory artifacts\swipe
2. 窗口固定 800×614 逻辑像素、WindowStyle=None、AllowsTransparency=false、不可 resize；
   背景是 DWM 原生 Acrylic（MainForm.cs 的 ApplyBackdrop() 用 DwmSetWindowAttribute(hwnd,38,…)，
   并特意做了 250ms 的「无材质 → Acrylic」两帧过渡避开黑闪）。
3. 界面全是手算坐标的 Canvas：三个页面 pageOverview / pageDpi / pageParams（NewPage() 建的 800×614
   Canvas，现在只靠 Visibility 切换）、左侧导航 navButtons（概况/DPI/参数/设置，x=10，y=96+i*66，
   56×56）、页脚从 y=560 起是一块卡片底。坐标是设计好的，一行都不要改。
4. 现在的切页逻辑在 src\MainForm.Layout.cs 的 SelectPage(PanelPage)：三个页面 Visibility 同帧一切、
   更新导航高亮、Invalidate()，没有任何动画。
5. 公用设施：Fonts.cs（命名字号）、Theme.cs（Ink/Muted/Accent…）、ColorBrush()、LineIcon()、
   CardTitle()、Meta()、AddButtonIn()、PlaceIn()。注释写中文，"说清楚为什么"。
6. src\SlideEase.cs 已存在（IEasingFunction，本次已按原则 4 改成 1−(1−t)³ + 末段 2% 回弹），
   目前零引用；直接用，别改回慢起曲线。

【交互与动效】
1. 热区：左侧导航列 x ≤ 84、y 88…364（标题条 y<76 是拖动窗口的区域，不要抢）。按住左键上下拖。
2. 拖动期（跟手，原则 4 的前半段）：
   - 页面位移 1:1 跟随指针，不加缓动；位移上限 160px，超出部分乘 0.35 阻尼；
     拖到两端（第一页再往下 / 最后一页再往上）整段乘 0.35。
   - 同时按进度 p = clamp(|offset| / 160, 0, 1) 做交叉淡化（原则 3）：
       · 当前页：Y = offset，Opacity = 1 − 0.5p，Blur = 5p
       · 相邻页：Y = offset + step·(56 − 40p)，Opacity = 0.2 + 0.8p，Blur = 6(1 − p)
     （step = +1 表示目标页在后面、从下方进来；向上滑 = 下一页）
3. 松手：位移 ≥ 80px 或松手瞬间速度 ≥ 520px/s → 提交；否则回弹。
   - 提交（原则 2：不飞出）：当前页 → Y = offset − step·48、Opacity 0、Blur 8；
     相邻页 → Y 0、Opacity 1、Blur 0。结束回调里隐藏旧页、清掉 Effect 与 CacheMode、更新状态。
   - 回弹：当前页 → Y 0、Opacity 1、Blur 0；相邻页 → Y = 56·step、Opacity 0、Blur 6，再隐藏。
4. 点击导航项：目标页从 step·40px 处淡入 + 去模糊，旧页移 −step·40px 后淡出 + 模糊，同一条缓动。
5. 时长与缓动：
   - 提交/入场基准 260ms，缓动 SlideEase.Shared。
   - 打断时重算：ms = clamp(剩余位移 / max(400, 松手速度) × 1000, 140, 340)。
   - 高亮块 navPill（56×56、圆角 12、底 #1F3B4BD8、描边 #333B4BD8，插在导航按钮**前面**）：
     选中项变化时用同一条缓动滑 Y，220ms；导航按钮自身 Background/BorderBrush 恒为 Transparent，
     颜色/字重仍给 navLabels。
6. 状态/文字切换也要交叉淡化（原则 3）：DPI 大数字换档、按钮文案在「读取 ↔ 读取中…」之间切换、
   导航文字颜色切换 —— 都做约 140ms 交叉淡化 + 0.96→1 缩放 + Blur 4→0，不要直接赋值硬切。
7. 模糊与缓存的取舍：过渡期间给页面 Canvas 设 `Effect = new BlurEffect { Radius = r }` 和
   `CacheMode = new BitmapCache()`（模糊大区域时缓存能省掉每帧的软件模糊）；
   过渡一结束立刻把两者清成 null —— 静止态绝不能留 Effect/CacheMode，否则小字会发糊。

【硬约束（违反就算没做完）】
1. 只动页面 Canvas 的 RenderTransform（TranslateTransform.Y）、Opacity、Effect、CacheMode。
   不要改 Canvas.Left/Top/Width/Height，不要增删布局元素，不要动页脚卡片底与任何坐标。
2. 不要给窗口本体做 Opacity/Scale 动画（原生 Acrylic 会掉材质/闪帧）；不要给内容加 ClipToBounds。
3. 尊重系统开关：SystemParameters.ClientAreaAnimation == false 或 HighContrast 为真时直接一步到位。
4. 拖动必须抢鼠标捕获（Mouse.Capture），否则导航按钮松手会触发 Click；同时在导航按钮（含「设置」）
   的 Click 处理里加守卫：这一轮发生过拖动就吞掉这次点击。
5. 打断要"就地结算"：新动画开始前 BeginAnimation(prop, null) 只用于把当前值取出来当起点，
   不要用它把元素瞬间弹回旧位置。
6. 不要动 TrayMenu.cs；不要动 src\Fonts.cs 与 src\MainForm.Appearance.cs —— 仓库里可能有别的工具
   在同时改，冲突就白干。
```
