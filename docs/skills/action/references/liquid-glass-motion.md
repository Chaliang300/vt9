# Liquid Glass 切换动效：规格 → 可落地映射

Apple Liquid Glass 风格的"切换动效"= 光学折射 + 流体表面张力 + 弹簧阻尼动力学。
下面是规格拆解、物理参数换算、以及**逐条的落地映射（能做的 / 只能近似的 / 做不到的）**。
"做不到"那几项必须写清楚，否则实现者会拿帧率去换一个根本做不出来的效果。

## 一、三个场景的规格拆解

### 1. 激活态 / 指示器流动切换（Metaball 黏连）

| 阶段 | 时间 | 形态 | 光学 |
| --- | --- | --- | --- |
| 形变与拉伸（张力） | 0–120ms | 光斑原位受力拉长，前端朝目标延伸；中部因表面张力变细 | 拉伸区透明度 −15%，边缘折射变锐 |
| 断开与黏连吸附 | 120–220ms | 尾端脱离、回缩；主体滑入目标位，落位瞬间 X 轴微膨胀到 1.08x 后平复 | — |
| 余波沉降 | 220–350ms | — | 中心泛出一圈 ~10% 透明度的高斯 Bloom，随后隐没 |

光学细节：**动态菲涅尔边缘**——受光面（朝光标/焦点）高光变亮、背光面泛暗，形成液体立体感。

### 2. 光标划过的焦点连续切换（Hover Waveform）

- **高斯衰减**：焦点从 A 移到 B 时，A 的放大系数沿高斯曲线落下、B 平滑抬起（不是各自独立的离散放大）。
- **垂直联动**：图标随放大纵向抬升 `TranslateY −8 → −16px`；相邻图标有约 **16ms 相位差**，形成水面推涌。
- **底座应力**：激活图标下方出现凹透镜放大形变，背后壁纸动态畸变。
- **高光追踪**：底座顶部镜面切边高光像水银一样跟随光标，在两图标中点变细、在图标正上方聚拢变亮。

### 3. 点击触发与呼出切换（Click-to-Launch）

| 阶段 | 时间 | 形态 |
| --- | --- | --- |
| 微压缩下潜 | 0–80ms | 整体缩至 0.92x，接触面下压；底座背景模糊 30px → 40px |
| 液态回弹 | 80–300ms | 弹性阻尼冲出并回弹（过冲 1.08x）；底部投出环形折射扰动波，掠过邻近元素后消散 |
| 窗口展开 | — | 从图标中心抽出半透明磨砂折射流体面，急速膨胀、毛玻璃过渡为实体窗口，圆角由大变小定型 |

## 二、物理参数 → 可直接算的数

规格给的是 Apple 的语义参数：`Response 0.32s`、`Damping Ratio 0.72`、`Mass 1.0`。

```
ω0 = 2π / response      = 2π / 0.32 ≈ 19.6 rad/s
k  = ω0² · m            ≈ 385            （劲度）
c  = 2ζ·ω0·m            ≈ 28.2           （阻尼）
过冲百分比 = exp(-πζ / √(1-ζ²))
             ζ=0.72 → ≈3.8%      ζ=0.6 → ≈8.0%（规格里 1.08x 那一下）
```

**两种实现路线，按需要选：**

| 路线 | 做法 | 何时用 |
| --- | --- | --- |
| A 时长 + 缓动 | `DoubleAnimation` + `IEasingFunction`（本技能 §二 的配方） | 简单的进场/退场、状态切换，行为确定、开销低 |
| B 弹簧积分器 | 每个受控属性存 `(x, v)`，逐帧半隐式欧拉：`v += (−k(x−target) − c·v)/m · dt; x += v·dt` | 需要**物理手感**、且要求打断绝对连续（Liquid Glass 这类） |

> B 路线是本技能"原则 1（可打断）"的最优解：**新目标只改 `target`，`x` 与 `v` 连续**，
> 天然没有"重放"这回事。用 `CompositionTarget.Rendering` 逐帧驱动即可（WPF 没有内建 spring easing）。
> 收表条件：`|x − target| < 0.1 && |v| < 0.5`（此时停表并把 x 精确写成 target）。

## 三、逐条落地映射

| 规格效果 | WPF 里的做法 | 保真度 |
| --- | --- | --- |
| metaball 黏连、颈部拉细 | 两个圆角形状之间插一段用 `Path` 动态贝塞尔的"脖子"，宽度随中心距插值；中心距 > `间距×1.2` 时宽度归零（对应规格的黏连阈值） | 近似（无 SDF 真融合） |
| 液滴断裂与吸附 | 0–120ms 内脖子保持、主体几乎不动；120–220ms 脖子收到 0、主体走弹簧到目标 | 近似 |
| 表面张力中部收细 | 非等比 `ScaleTransform`（运动轴拉长、垂直轴收窄）配合 `SkewTransform` | 近似 |
| 动态菲涅尔边缘 | 两条 `LinearGradientBrush` 描边，按运动方向插值角度与不透明度（受光面变亮、背光面变暗） | 近似 |
| 余波 Bloom 脉冲 | 指示器**下方** z 序放一个 `RadialGradientBrush` 椭圆：透明度 0.1、半径 0→1.6x、250ms 淡出 | 可做 |
| 高斯衰减鱼眼波峰 | 每个对象的目标缩放 `1 + A·exp(−(d/σ)²)`，`d` 为到焦点的距离 | 可做 |
| 相邻元素 16ms 相位差 | 每个对象对"自己的目标"加一阶滞后：`x' += (x_target − x')·dt/τ`，`τ ≈ 16–30ms` | 可做 |
| 高光跟随光标（镜面切边） | 一条渐变描边，高光中心与不透明度（0.35 → 0.75）用弹簧跟随焦点 | 可做 |
| 点击微压缩 | `ScaleTransform 0.92`（弹簧，0–80ms）+ 内容层 `BlurEffect` 半径加深 | 可做（模糊的是自己，不是壁纸） |
| 环形折射扰动波 | 描边椭圆：半径 0→1.8x、`StrokeThickness 2→0`、透明度 0.25→0、280ms，可叠小半径模糊 | 可做 |
| **底座凹透镜畸变（背后壁纸被放大）** | **做不到**：WPF 无法对 DWM 合成的背景做逐帧折射/位移采样。只能做内容层的假高光、假渐变 | 降级 |
| **底座背景模糊 30→40px 动态插值** | **做不到**：DWM Acrylic/云母的模糊半径不是可逐帧动画的属性；能在预设材质间切换（会跳变），别逐帧改 | 降级 |
| **Liquid Sheet 展开出实体窗口** | 仅在"窗口由应用自绘"时可行；系统窗口只能在内容层做一块从图标位置展开的磨砂面板 | 降级 |

降级时的替代口径：**光学做不到，就换成"光影语言"**——用高光、Bloom、渐变描边的方向与强弱变化，
让人读到"有东西在流动、在受压、在回弹"，而不是硬上假折射。观感上 80% 的液体感来自这三样。

## 四、与本技能已有原则的衔接

1. 规格里 0–120ms 的"张力拉伸"**不是慢起**：位置不动，但形状与高光在**第一帧**就变了，
   所以"起步快、第一帧有反馈"这条没有被破坏。要动位置时才必须立即有速度。
2. 弹簧积分器（路线 B）天然满足"可随时打断"，比重算时长更彻底。
3. "余波沉降 220–350ms"与原则 4 的"末段回弹"说的是同一件事：一个描述形状（Bloom），一个描述位置（2% 过冲）。

## 五、落地顺序（按性价比）

1. **通用的 `Spring` 小类**（一个属性挂一个实例，逐帧积分 + 收表）——它同时买下"物理手感"和"绝对可打断"。
2. 指示器的 metaball 近似 + Bloom 余波。
3. 鱼眼波形 + 相位差（列表、Dock、导航栏通用）。
4. 镜面高光追踪、点击压缩 + 回弹、环形涟漪。
5. 折射畸变与动态背景模糊：**写清做不到**，用高光/渐变替代，不要拿帧率换幻觉。
