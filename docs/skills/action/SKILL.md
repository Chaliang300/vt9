# 可打断的界面动效

一段动效是否"高级"，八成取决于它是否**跟手、可打断、柔和**，而不是曲线多花哨。
慢起、飞出屏幕、关键帧重放、硬切——这四件是"AI 感"的主要来源。

## 一、四条原则（优先级高于任何参数）

| # | 原则 | 禁止 | 必须 |
| --- | --- | --- | --- |
| 1 | 只用**可随时打断**的过渡动画 | `DoubleAnimationUsingKeyFrames`、Storyboard 关键帧（打断就得从头重放） | 一律 from→to 的属性动画；新输入到来时**读当前值续接**，时长按剩余距离缩放 |
| 2 | **退场不飞出屏幕** | 元素滑出、飞出视口 | 只移 ≤48px，主要靠淡出 + 高斯模糊收尾 |
| 3 | **状态/图标/文案切换不硬切** | 一帧直接赋值换掉 | 交叉淡化 + 0.96→1 缩放 + Blur 4→0，约 140ms |
| 4 | **入场起步快、收尾轻** | 慢起（ease-in）、匀速（linear） | ease-out（`1−(1−t)³`）+ 末段 2% 回弹 |

关于第 4 条的常见误解：用户嘴上说"先拉长再加速"时，那段"拉长"应该由**手指拖拽**承担（拖动期 1:1 跟手、不加缓动），
松手后的动画必须一上来就有速度。把慢起写进动画曲线，只会让界面显得不跟手。

## 二、成套配方

`step = +1` 表示目标在后方（从下方/右侧进场），`-1` 反之。`p` 是拖动进度。

### A. 拖动期：1:1 跟手 + 进度驱动交叉淡化

- 位移 1:1 跟随指针，**不加缓动**；上限 160px，超出部分乘 0.35 阻尼；拖到数据两端整段乘 0.35。
- 进度 `p = clamp(|offset| / 160, 0, 1)`，按 p 同步做交叉淡化：

| 元素 | 位移 | 不透明度 | 模糊半径 |
| --- | --- | --- | --- |
| 当前页 | `offset` | `1 − 0.5p` | `5p` |
| 相邻页 | `offset + step·(56 − 40p)` | `0.2 + 0.8p` | `6(1 − p)` |

手指走到哪，旧页就淡到哪、新页就清晰到哪——"跟手"由此从形容词变成可验收的公式。

### B. 松手：判定阈值 → 提交或回弹

- 提交：`|offset| ≥ 80px` 或松手瞬间速度 `≥ 520px/s`。
- 提交（进场 ≤48px + 淡出 + 模糊，不飞出）：
  当前页 → `Y = offset − step·48`、`Opacity 0`、`Blur 8`；相邻页 → `Y 0`、`Opacity 1`、`Blur 0`。
- 回弹：当前页 → `Y 0`、`Opacity 1`、`Blur 0`；相邻页 → `Y = step·56`、`Opacity 0`、`Blur 6`，随后隐藏。
- 结束回调里：隐藏旧元素、清空 `Effect` 与 `CacheMode`、更新选中态、写一条完成日志。

### C. 点击切换：同一套，只是起点是静止状态

目标从 `step·40px` 处淡入 + 去模糊，旧目标移 `−step·40px` 后淡出 + 模糊，基准 260ms。

### D. 状态 / 图标 / 文案切换

DPI 数值换档、按钮文案在「读取 ↔ 读取中…」之间切换、选中态文字换色——统统
**140ms 交叉淡化 + 0.96→1 缩放 + Blur 4→0**，不要直接赋值。禁止一帧换掉的图标。

### E. 打断续接（原则 1 的核心）

```
新目标到来时：
  1. 读该属性当前值（动画进行中读到的就是当前插值，正好当起点）
  2. 清掉旧动画、把当前值固定成新的基准值
  3. 从它动画到新目标，时长重算：
     ms = clamp(剩余距离 / max(400, 松手速度) × 1000, 140, 340)
```

绝不能"清动画 + 设回旧值 + 重新播放"——那是重放，不是打断。

需要**物理手感**时（Liquid Glass 那一类），把路线换成**弹簧积分器**：每个受控属性存 `(位置 x, 速度 v)`，
新目标只改 `target`，`x` 与 `v` 天然连续——打断不再是"续接"而就是它本来的工作方式。见 §八。

### F. 指示器 / 胶囊（透镜式 Dock 配方）

一带多（tab / dock / 导航高亮）的指示器，用"两层 + 剪裁"就能做出折射错觉：

1. **透镜剪裁**：底层放常态标签；上面再放一份放大约 1.1x、颜色换成强调色的标签层，
   整层裁在指示器的圆角矩形里（网页用 `clipPath`，WPF 用 `Clip = new RectangleGeometry(...)`）。
   指示器与剪裁窗口**共用同一组 transform** —— 一旦不同步，折射幻觉立刻塌。
   顺带好处：激活项自动变强调色，不必另写选中态样式。
2. **体积守恒形变**：`stretchY = clamp(1 + v·0.0002, 1, 1.10)`（v 为 px/s）、`compressX = 1/√stretchY`。
   上限 1.10 是"液体"与"橡皮筋"的分界。
3. **指数阻尼硬边界**：越界位移 `damped = allowedTravel·(1 − e^(−pull/40))` —— 渐近逼近硬边界、永不越过，
   比线性阻尼好（后者要额外 clamp，手感是断的）；贴到壁上时把 `stretchY` 换成 `0.96`，
   做出"被挤在壁上"的暗示。
4. **松手分两路**：贴壁 → 过冲回弹（≈`BackEase{0.25, EaseOut}`）；普通 → 强减速长尾（≈`QuarticEase{EaseOut}`），
   时长随距离缩放。
5. **拖拽滞后是有意为之**：指示器可以带 τ ≤ 30–80ms 的一阶滞后（"重液滴"感）；**内容/页面不能**，必须 1:1。
   滞后一律写成 `alpha = 1 − exp(−dt/τ)`，别写"每帧乘 0.08"（帧率一变手感就变）。

完整 SVG 拆解（四层结构、六个可带走的技术、四处必改的坑、WPF 对应写法）见 `references/liquid-lens-dock.md`。

### G. 巡航弹道（加速 → 巡航 → 刹车，第三条路线）

长距离滑行（dock / tab 指示器跨好几个 item）用**显式速度剖面**，比一条大缓动好调：

```
accel      = 1620 px/s²                      （≈0.45 px/帧² @60fps）
vmax       = min(432, 270 + 距离·0.72) px/s   （≈4.5–7.2 px/帧）
刹车区      = clamp(距离·0.15, 18, 60) px      → 进区后交给软着陆缓动（≈0.78s，过冲 ≈10%）
```

四条口径：

- **起跑必须继承松手速度**：拖动后松手用测得的速度当 `vel` 初值，否则快速甩动会"先死停再重新起步"——
  这正是"不跟手"最典型的症状。只有"从未拖动过的点击"才允许从 0 起跑，且加速段 ≤8–10 帧（130–170ms）。
- **末段回弹要做成绝对像素**（+4–6px 再回落），别指望"小刹车区 × 小过冲"能看见：
  固定 18px 刹车区 × 2% 过冲 ≈ **0.4px**，肉眼不可见。
- **巡航期拉伸用比值归一化**（`1 + (v/vmax)·0.08`）才抗帧率；用绝对速度就回到帧率依赖的老问题。
- **时长口径**：指示器/胶囊 0.6–1.2s 可接受；内容入场仍走 A / B 路线，0.2–0.34s。

## 三、默认参数表

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 入场/提交基准时长 | 260ms | 复杂转场（整页切换）可到 340ms |
| 状态切换时长 | 140ms | 图标、文案、颜色 |
| 高亮块/指示器滑动 | 220ms | 同一组元素间移动 |
| 拖动位移上限 | 160px | 超出阻尼 0.35 |
| 提交距离阈值 | 80px | 或速度 520px/s |
| 起始偏移（入场） | 40–56px | 不要更大，飞去飞回就是"AI 感" |
| 退场位移 | ≤48px | 配合淡出 + 模糊 |
| 末段回弹 | 2% 行程 | 614px 行程约 12px，"轻微"的量级 |
| 弹簧（Liquid Glass 层） | `response 0.32s` / `ζ 0.72` / `mass 1.0` | 换算 `ω0≈19.6`、`k≈385`、`c≈28.2`，过冲 ≈3.8%；要 8% 过冲（视觉上的 1.08x）把 ζ 降到 0.6。见 §八 |
| 巡航弹道（指示器长距离滑行） | `accel 1620 px/s²`、`vmax 270–432 px/s`、刹车区 `clamp(距离·0.15, 18, 60)px` | 第三条路线，见 §二 G；末段回弹要做成**绝对像素** |

曲线（起步快收尾轻 + 末段回弹）：

```csharp
double main = 1 - Math.Pow(1 - t, 3);                     // ease-out：t=0 处斜率最大
double settle = t > 0.75                                  // 末段 2% 过冲再收回
    ? 0.02 * Math.Sin(Math.PI * (t - 0.75) / 0.25) : 0;
return main + settle;
```

## 四、三件必须做的工程事

1. **模糊要配缓存**：过渡期间给被模糊的元素设 `BlurEffect` 且 `CacheMode = new BitmapCache()`，
   省掉每帧对大片区域做软件模糊；**过渡一结束立刻把 `Effect` 和 `CacheMode` 清成 `null`**——
   静止态留下它们会让小字发糊、还一直烧 GPU。
2. **尊重系统开关**：`SystemParameters.ClientAreaAnimation == false`（"在 Windows 中显示动画"关掉）、
   `SystemParameters.HighContrast` 为真时，直接一步到位，不播动画。
3. **拖拽要抢捕获**：拖动开始时 `Mouse.Capture`，否则原来的按钮/链接在松手时还会触发 Click；
   同时在 Click 处理里加"这一轮发生过拖动就吞掉"的守卫。

## 五、不要做的事

- **不要动布局属性**（`Left/Top/Width/Height/Margin`）：会触发每帧重新测量与排版，
  手算坐标的界面还会把描边、命中区一起带偏。只用 `RenderTransform` 与 `Opacity`。
- **不要给窗口本体做 Opacity/Scale 动画**：窗口背景若是 DWM 合成的原生 Acrylic/云母，
  动它会把渲染推回分层窗口路径，掉材质、闪一帧。
- **不要用关键帧**（见原则 1）；**不要慢起**（见原则 4）。
- **不要为了动画改数据流**：动画只是把状态变化"接住"，状态本身该瞬时确定。

## 六、验收清单

- [ ] 每种转场都在**完成回调**里写一条日志（含目标名），跑一次自动化预览能在日志里看到它——
      "丝滑"是时间维度的，普通截图证明不了动画播过。
- [ ] **打断测试**：转场进行到一半时触发新的切换，画面必须从当前位置/当前模糊与透明度续接，
      不能闪回起点重放。
- [ ] **静止态检查**：动画结束后 `Effect`、`CacheMode` 都是 `null`，属性回到精确终值。
- [ ] **中途截图**：在截图前 ~80ms 触发切换，截图上应停在半位移/半透明状态
      （WPF 可用 `System.Drawing.Bitmap.GetPixel` 采样，注意截图像素 = 逻辑坐标 × 缩放比）。
- [ ] **降级路径**：关掉系统动画后，一切瞬时到位且不报错。

## 七、调参口径

| 症状 | 调法 |
| --- | --- |
| 交叉淡化看起来"糊" | 旧页淡出更快（`1 − 0.7p`）、模糊上限降到 4、新页起始不透明度 0.2 → 0.35 |
| 低配机掉帧 | 模糊半径减半；或退场只做淡出不做模糊（原则保全，帧率先行） |
| 觉得"不够跟手" | 检查拖动期是否被加了缓动；检查打断是否走了"读当前值续接" |
| 觉得"太飘" | 缩小起始偏移（40→24px）、把回弹从 2% 降到 1%，不要加时长 |

## 八、Liquid Glass 光学层（可选叠加）

Apple Liquid Glass 的切换动效 = 光学折射 + 表面张力 + 弹簧阻尼。要叠这一层时：

- **物理**：`response 0.32s / ζ 0.72 / mass 1.0` → `ω0≈19.6`、`k≈385`、`c≈28.2`、过冲 ≈3.8%。
  三个场景：**指示器 Metaball 黏连**（黏连阈值 = 元素间距 × 1.2，超过即断开）、
  **光标划过的鱼眼波峰**（目标缩放 `1 + A·exp(−(d/σ)²)`，相邻元素 16ms 相位差）、
  **点击呼出**（0.92x 微压缩 → 1.08x 回弹 → 环形涟漪 → 面板展开）。
- **光学**：Bloom 余波（10% 透明度径向辉光）、镜面切边高光追踪（0.35 → 0.75）、
  动态菲涅尔边缘（受光面亮、背光面暗）。
- **张力相不是慢起**：0–120ms 位置不动但形状与高光**第一帧就变**，原则 4 没有被破坏；要动位置时必须立即有速度。
- **做不到的要坦率写下来**：DWM 合成背景的实时折射、Acrylic 模糊半径的逐帧插值、系统窗口的 Liquid Sheet 展开——
  WPF 做不到，改用高光 / 渐变 / 辉光的"光影语言"替代（液体感 80% 来自这三样），不要拿帧率换一个做不出来的效果。

逐条的"可做 / 近似 / 降级"与公式见 `references/liquid-glass-motion.md`。
指示器/胶囊那条线（透镜剪裁 + 体积守恒形变 + 指数阻尼硬边界）另见 §二 F 与 `references/liquid-lens-dock.md`。
